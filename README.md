# GenC Cognizant Digital Nurture 4.0 - FSE Exercise Solutions

This repository contains the solutions for the hands-on exercises completed during the GenC Cognizant Digital Nurture 4.0 program for the Full Stack Engineer track.

## Weekly Breakdown

The exercises are organized by week, covering a wide range of topics essential for Full Stack Development.

*   **Week 1: Data Structures & Algorithms, Design Principles & Patterns**
    *   E-commerce Platform Search Function
    *   Financial Forecasting
    *   Implementing the Singleton Pattern
    *   Implementing the Factory Method Pattern

*   **Week 2: PL/SQL, Logging & TDD**
    *   PL/SQL Control Structures & Stored Procedures
    *   SLF4J Logging Framework
    *   Test-Driven Development (TDD) with JUnit 5 & Mockito

*   **Week 3: Spring Framework**
    *   Spring Core, Dependency Injection, and Maven
    *   Spring Data JPA with Spring Boot & Hibernate

*   **Week 4: Spring REST & Web Services**
    *   Creating RESTful Web Services with Spring Boot 3
    *   Authentication with JWT
    *   Building various REST endpoints for different use-cases

*   **Week 5: Microservices**
    *   Introduction to Microservices with Spring Boot 3 and Spring Cloud

*   **Week 6 & 7: React**
    *   Fundamentals of React: Creating components, state, and props
    *   Building various React applications like a Student Management Portal, Score Calculator, Blog, and more.
    *   Handling events and building complex UIs.

*   **Week 8: Git**
    *   Hands-on labs for learning Git version control.

## Navigation

Each week's solutions are organized into their respective folders. Inside each exercise folder, you will typically find a `code` directory containing the source code and an `output` directory with relevant screenshots or results.
